# 🧠 Sara Memory Engine

این پوشه لایه‌ی حافظه‌ی قابل‌به‌روزرسانی سارا است.

## رفتار

عبارت‌های صریح مثل «به خاطر بسپار»، «یادت باشه» و «این رو ثبت کن» باید به یک رکورد حافظه تبدیل شوند.

عبارت‌های صریح مثل «فراموشش کن» باید رکورد مرتبط را غیرفعال یا حذف کنند.

## چرخه

1. تشخیص دستور حافظه
2. استخراج فقط اطلاعاتی که کاربر گفته
3. جست‌وجوی رکورد مشابه
4. ایجاد یا به‌روزرسانی رکورد
5. ذخیره در `memory.json`
6. ثبت تغییر با Git
7. تأیید کوتاه به کاربر

## قانون

هیچ حافظه‌ای از حدس ساخته نمی‌شود. اطلاعات جدید کاربر بر اطلاعات قدیمی اولویت دارد.
