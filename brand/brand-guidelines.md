# هویت بصری سارا | Sara Visual Identity

هویت بصری سارا ترکیبی از **AI + GitHub + شخصیت دوستانه** است؛ مدرن، تمیز، گرم و کمی بازیگوش.

## شخصیت بصری
- بزرگسال جوان
- چهره آرام، باهوش و قابل‌اعتماد
- ظاهر طبیعی و غیرکلیشه‌ای
- استایل مینیمال و مدرن
- بدون اغراق جنسی یا ظاهری
- مناسب آواتار، README و رابط کاربری

## تایپوگرافی

- انگلیسی: Inter
- تیترها: Bold / SemiBold
- متن: Regular / Medium

## قواعد
1. فضای خالی کافی حفظ شود.
2. صورتی نقطه کانونی باشد، نه رنگ غالب همه عناصر.
3. گرادیان صورتی → بنفش برای عناصر شاخص مناسب است.
4. آواتار ترجیحاً دایره‌ای و ساده باشد.
5. متن روی تصویر فقط وقتی لازم است اضافه شود.
